# SUP26-018 · Aurora / Rainbow Bridge Web 应用 XSS、SSRF 披露簇

> 补充线索卡｜2026-09-24 核读官方奖励台账｜主表外；披露簇尚未拆成独立事件。

## 1. 基本信息

- 对象：`RAINBOWBRIDGE.APP` 与 Aurora 相关 Web 应用；具体域名和部署清单未公开。
- 时间：官方台账仅明确 **2022-12-01 发放奖励**；各漏洞的发现、报告日期未给出。
- 裁决：官方确认收到多项 XSS、SSRF 等 Web2 漏洞报告；尚无证据证明发生跨链资产事故。

## 2. 原因、经过与资金影响

官方把多项问题归于不同域名的 NextJS 配置，并列举可能产生的钓鱼、钱包接管、伪造交易和资金盗取风险。这是**风险场景**，不是这些后果已发生的证明。台账没有提供各漏洞的独立技术细节、根交易或损失。**5 万美元奖励不能作盗损金额。**

## 3. 是否解决、如何解决

台账表达了修补安全问题的意向，但未列每个域名的修复版本和部署核验。处置结果仍待确认。

## 4. 证据与待确认

- [Aurora 官方奖励台账](https://forum.aurora.dev/t/bug-bounty-program-reports-and-rewards/1257)，“Multiple Stored XSS and SSRF vulnerabilities”段；2026-09-24 核读。
- 待补每份报告、域名与漏洞一一对应、报告日、修复版本及真实跨链影响。披露簇不按漏洞个数拆算攻击。
